# ITCONIC — Team Links

صفحة روابط فريق ITCONIC على منصات التواصل. HTML + CSS + JavaScript بدون أي إطار عمل.

- تعديل الروابط والنصوص: `js/content.js`
- الألوان والخطوط: `css/style.css` (قسم المتغيرات)
- التشغيل محلياً: `python3 -m http.server 8000` ثم افتح http://localhost:8000
- النشر: GitHub Pages — أي `git push` على الفرع `main` ينشر تلقائياً.
